MonkeyClimber Web版：回復ストック・スキン解放・背景模様変更

index.html をChrome/Edgeで開いて遊べます。
SPACE/↑: ジャンプ、ESC: ポーズ

・バナナ10個でハート1個分の回復。満タンなら回復ストックを1追加。
・ダメージを受けるとストックを1個自動消費して即回復（ダメージ演出は残る）。
・地面は画面下まで続く表示に変更。
・背景と壁の模様が85mごとに変わる（地下・森林・空・宇宙のゾーン分けは復活しません）。
・ノーマル200/400/500m、ハード200/400/500mで計6種類のスキン解放。
・タイトルの「サルのスキンを選ぶ」から選択可能。
・最高記録、ハード解放、スキン解放はブラウザのlocalStorageに保存。
・これまでのゲーム機能とPNG画像は引き継ぎ。

注意：JavaScriptの構文チェックは実施しますが、全高度のプレイテストは未実施です。
