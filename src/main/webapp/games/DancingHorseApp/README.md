# 🐴🕺 Dancing Horse Revolution (HTML5 / JavaScript)

馬が四足歩行から仁王立ちして踊り出す本格リズムゲームのHTML5/JavaScript版です。
ブラウザ（Google Chrome, Microsoft Edge, Safari, Firefox 等）でそのまま動作します。

| Track | 曲名 | ジャンル | BPM | 演奏時間 | 特徴 |

## 🚀 起動方法

### 方法 1: バッチファイルをダブルクリック
フォルダ内の **`play_game.bat`** をダブルクリックすると、ブラウザでゲームが起動します。

### 方法 2: 直接ブラウザで開く
**`index.html`** をお使いのブラウザにドラッグ＆ドロップ、またはダブルクリックして開いてください。

## 🎮 操作方法

### 【曲選択画面 (MUSIC SELECT)】
- **`↑` `↓`** または **`W` `S`** / **曲カードクリック**: プレイする楽曲を選択
- **`←` `→`** または **`A` `D`** / **ボタンクリック**: 難易度切り替え（NORMAL ⇔ HARD）
- **`Space`** または **`Enter`** / **「GAME START」ボタンクリック**: ゲーム開始！

### 【ゲームプレイ中】
- **`←` `↑` `↓` `→`** または **`A` `W` `S` `D`**: 4レーンのリズムステップ（ノーツ判定）
- **画面クリック / タップ**: 各レーンを直接タップしても判定可能（スマホ・マウス対応）
- **`Tab`**: 仁王立ち ⇔ 四足歩行（草ハムハム 🌱）手動切り替え
- **`Space`** または **`F`**: フィーバー発動（ゲージMAX時：トルネード大回転ダンス！）
- **`R`**: 曲の最初から即座にリトライ
- **`Esc`** または **`P`** / **画面右上「⏸ MENU」ボタン**: ポーズメニューを開く

### 【ポーズメニュー（一時停止中）】
曲を間違えて選んだ場合ややり直したい場合にいつでも利用できます：
- **`Space`** / **`Enter`** / **「ゲームを再開する」クリック**: そのまま再開
- **`R`** / **「最初からやり直す」クリック**: 同じ曲を頭からリスタート
- **`Esc`** / **`Backspace`** / **`Q`** / **「曲選択（ホーム）に戻る」クリック**: **曲選択画面（MUSIC SELECT）に戻る**

### 【リザルト画面】
- **`Space`** または **`R`**: 同じ曲をリトライ
- **`Esc`**: 曲選択画面（MUSIC SELECT）に戻る
